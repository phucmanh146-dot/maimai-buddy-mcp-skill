# 优惠与价格核验清单

在推荐优惠组合前，逐项核对以下内容。没有证据的项目标注“待确认”。

## 商品与价格
- [ ] 商品名称、规格、数量是否一致
- [ ] 单价来自哪里，何时看到
- [ ] 套餐内容是否与单点商品相同
- [ ] 是否存在门店、时段或渠道差价

## 优惠券
- [ ] 有效期与适用时段
- [ ] 适用门店 / 城市 / 下单渠道
- [ ] 指定商品、规格与数量限制
- [ ] 最低消费门槛如何计算
- [ ] 是否要求会员身份或特定支付方式
- [ ] 是否可与其他优惠叠加
- [ ] 是否限新客、限账户或限使用次数
- [ ] 优惠后金额是否仍满足其他优惠条件

## 计算与呈现
- [ ] 逐项列出商品小计
- [ ] 将已核实优惠与条件性优惠分开
- [ ] 写清估算总价、人均与预算余量
- [ ] 明确未核验的价格、门店规则和库存
- [ ] 提醒用户以官方下单页面最终展示为准

## 推荐原则
先满足用户预算和实际需求，再比较价格。不要为了凑优惠推荐用户不需要的商品；若为了达到门槛需要多买商品，应比较“多买后的总支出”与“实际节省”。
